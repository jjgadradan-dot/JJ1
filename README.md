# 🚀 XR

دروازه (Gateway) سریع و مدرن برای تونل‌زنی VLESS روی WebSocket و XHTTP + HTTP Proxy، با داشبورد مدیریتی زیبا، **ربات مدیریت تلگرام**، صفحات ساب حرفه‌ای و قابلیت ساخت لینک‌های اختصاصی با محدودیت ترافیک، سرعت و آی‌پی.

## ✨ ویژگی‌ها

* 🔌 تونل VLESS روی چند ترابرد قابل‌انتخاب: **WebSocket**، **XHTTP (packet-up)** و **XHTTP (stream-up)**
* 🌐 HTTP Proxy داخلی
* 📊 داشبورد مدیریتی کامل (آمار، نمودار ترافیک ساعتی، اتصالات زنده، لاگ فعالیت‌ها و خطاها)
* 🔗 مدیریت لینک‌های نامحدود با محدودیت ترافیک اختصاصی (KB/MB/GB)
* 🚦 محدودیت سرعت (Bandwidth Throttling) اختصاصی برای هر کانفیگ، بر حسب Mbps
* ✅ فعال/غیرفعال‌سازی هر لینک به‌صورت لحظه‌ای، و انقضای خودکار بر اساس روز
* 📊 نمایش خودکار حجم مصرفی، حجم باقی‌مانده و تاریخ انقضا داخل v2rayNG / Hiddify / Clash / Streisand (هدر `subscription-userinfo` + ردیف‌های جدا برای حجم و لوکیشن)
* 🔀 **چهار پروتکل روی یک ساب مشتری**: هر لینک ساب، چهار کانفیگ جدا (VLESS-WS، XHTTP، Trojan، VMess) از همان UUID می‌سازد تا اگر یکی فیلتر شد بقیه کار کنند
* 📱 خروجی QR Code برای هر لینک و هر ساب
* 🛡️ Fingerprint (uTLS) و ALPN قابل تنظیم دستی برای هر کانفیگ
* 🔢 پورت اتصال قابل تنظیم دستی برای هر کانفیگ (نه فقط 443)
* 🌐 **دامنه اختصاصی / CDN سراسری** (از Nyx Panel): با تنظیم یک دامنه CDN (Cloudflare، آروان و...) در تنظیمات، همه کانفیگ‌ها و لینک‌های ساب با آن دامنه ساخته می‌شوند به‌جای دامنه اصلی سرور
* 🎯 دامنه CDN اختصاصی برای هر کانفیگ (فیلد جداگانه هنگام ساخت/ویرایش) — از متغیر `CDN_DOMAIN` هم می‌توانید مقدار اولیه را تعیین کنید
* 🛡️ **سامانه هوشمند سوئیچ خودکار SNI** (از Nyx Panel): دیمون پس‌زمینه که هر ۶۰ ثانیه اتصال TLS دامنه‌های SNI را زنده تست می‌کند و در زمان فیلتر شدن/قطعی نت، خودکار به سالم‌ترین دامنه لیست سفید (بانک‌ها، آروان و...) سوئیچ می‌کند — بدون تغییر لینک کاربران، با هشدار تلگرام و دکمه اجرای دستی در پنل و ربات
* 👥 محدودیت تعداد آی‌پی/کاربر هم‌زمان به‌ازای هر کانفیگ
* 🗂 **گروه‌های ساب**: چند کانفیگ رو داخل یک گروه بذار و یک لینک ساب حرفه‌ای و زیبا (صفحه‌ی عمومی، قابل رمزدار کردن) برای همه‌شون بگیر
* 💾 ذخیره‌سازی وضعیت روی دیسک (نه فقط حافظه) تا با ری‌استارت سرویس از بین نره — به شرطی که یک Volume دائمی روی مسیر دیتا وصل باشه
* 🚀 **بخش تغییرات پنل**: تاریخچه کامل نسخه‌ها و بروزرسانی‌ها (جدید / بهبود / رفع اشکال) با قابلیت فیلتر، داخل خود پنل
* 🤖 **ربات مدیریت تلگرام** (اختیاری) برای مدیریت کامل کانفیگ‌ها و گروه‌های ساب، بدون نیاز به باز کردن پنل وب
* ⚛️ **موتور مسیریابی چندگانه کوانتومی** (از Nyx v2.3.0): پایش موازی ۴ مسیر ارتباطی مستقل (TLS مستقیم، CDN داخلی ایران، تونل DNS پورت ۵۳، پینگ ICMP) هر ۱۵ ثانیه با امتیازدهی ۰–۱۰۰ و انتخاب خودکار بهترین مسیر
* 🚨 **حالت اضطراری (Panic Mode)** با منطق Hysteresis: پس از ۳ چک متوالی ناموفق فعال و با ۲ چک موفق رفع می‌شود؛ هشدار و پیام بازیابی با مدت دقیق قطعی به تلگرام ادمین می‌رود
* ⚖️ **لودبالانسر هوشمند**: هر ۳۰ ثانیه کانفیگ‌ها بر پایه تاخیر، پایداری و آپتایم نمره می‌گیرند تا سالم‌ترین سرور همیشه در ردیف اول سابسکریپشن باشد
* 🔐 **پروتکل Trojan روی WebSocket**: رلهٔ کامل و واقعی استاندارد trojan-gfw با احراز هویت SHA-224
* 🔐 **پروتکل VMess روی WebSocket**: رلهٔ واقعی با احراز هویت AEAD (AES-128-GCM / ChaCha20-Poly1305) — سازگار با v2rayNG، Hiddify و NekoBox
* ⚡ **پکت فرگمنت** با پریست‌های تست‌شدهٔ اپراتورها: همراه اول، ایرانسل و اینترانت + حالت دستی
* 🎨 **برندینگ صفحه مشتری** (`/subinfo/{uuid}`): نام فروشگاه، لوگو، رنگ، دکمه‌های پشتیبانی و تمدید، کادر اعلان و باکس دانلود ۱-کلیک نرم‌افزارها
* 🔍 **جستجوی لحظه‌ای** کانفیگ‌ها و گروه‌ها بر اساس نام، UUID، پروتکل، پورت، SNI، دامنه، لوکیشن و وضعیت — با پشتیبانی از اعداد فارسی
* 💾 **بکاپ خودکار در تلگرام** با کد اعتبارسنجی SHA-256 و **بازیابی ۱-کلیک** (کافی است همان فایل را دوباره برای ربات بفرستید)
* 🌐 **خروجی کلودفلر WARP**: رفع تحریم OpenAI، Claude، Netflix و Spotify + مخفی‌سازی IP سرور، با رفتار fail-open
* 🖥️ **مستر و نود همزمان**: هم می‌تواند پنل‌های XR / Marzban / 3x-ui را به‌عنوان نود مدیریت کند، هم خودش با API توکن‌دار به یک پنل مستر دیگر وصل شود

## 1️⃣ Fork روی گیت‌هاب

ابتدا روی دکمه Fork کلیک کنید تا این ریپازیتوری را به حساب خود منتقل کنید.

## 2️⃣ Deploy روی Railway

1. وارد سایت [Railway.app](https://railway.app/) شوید.
2. روی New Project → Deploy from GitHub repo کلیک کنید.
3. ریپازیتوری Fork شده را انتخاب کنید.
4. Railway به‌صورت خودکار پروژه را Deploy می‌کند.

💡 پس از دیپلوی، یک دامنه عمومی (Public Domain) برای سرویس خود از تنظیمات Railway فعال کنید تا متغیر `RAILWAY_PUBLIC_DOMAIN` به‌درستی مقداردهی شود.

### 💾 ذخیره‌سازی دائمی (Volume)

وضعیت سرویس (کانفیگ‌ها، آمار مصرف، گروه‌های ساب، رمز ادمین) روی فایل `x4g_state.json` داخل مسیر `DATA_DIR` (پیش‌فرض `/data`) ذخیره می‌شود. برای این‌که این اطلاعات با هر ری‌استارت یا دیپلوی جدید روی Railway از بین نرود، حتماً یک **Volume** بسازید و آن را روی همان مسیر (`/data`) به سرویس متصل کنید (از تنظیمات سرویس → بخش Volumes). بدون این کار، اطلاعات فقط روی همان کانتینر فعلی می‌مانند و با تعویض کانتینر پاک می‌شوند.

## 3️⃣ اتصال به کانفیگ‌ها

پس از دیپلوی موفق:

1. به آدرس `https://your-app.up.railway.app/dashboard` بروید.
2. در صفحه داشبورد کلی، لینک VLESS پیش‌فرض (بدون محدودیت) را مشاهده و کپی کنید.
3. این لینک را در کلاینت دلخواه (v2rayNG، NekoBox، Streisand و...) وارد کنید.
4. برای ساخت لینک‌های جداگانه با محدودیت ترافیک، سرعت، آی‌پی و... به بخش مدیریت لینک‌ها بروید.

## 🔧 تنظیمات دستی هر کانفیگ

هنگام ساخت یا ویرایش هر کانفیگ می‌توانید این موارد را جداگانه تنظیم کنید:

* **پروتکل/ترابرد**: `vless-ws` (VLESS روی WebSocket) یا یکی از حالت‌های XHTTP (`xhttp-packet-up` / `xhttp-stream-up`)
* **Fingerprint (uTLS)**: مقادیر chrome / firefox / safari / ios / android / edge / 360 / qq / random / randomized
* **ALPN**: پیش‌فرض پروتکل، یا مقدار دستی مثل `h2,http/1.1` یا `http/1.1`
* **پورت اتصال**: هر پورتی بین 1 تا 65535 (نه فقط 443) — دقت کنید که این پورت باید واقعاً روی دامنه/سرویس شما باز و در دسترس باشد
* **محدودیت حجم**: بر حسب KB/MB/GB (0 = نامحدود)
* **محدودیت سرعت**: بر حسب Mbps، به‌صورت مستقل برای هر کانفیگ (0 = نامحدود)
* **محدودیت آی‌پی هم‌زمان**: تعداد آی‌پی/کاربری که مجاز است هم‌زمان از همان کانفیگ استفاده کند (0 = نامحدود)
* **انقضا**: تعداد روزهای اعتبار کانفیگ (بدون مقدار = بدون انقضا)
* **دامنه CDN اختصاصی**: یک دامنه/ساب‌دامین CDN مخصوص همان کانفیگ (اختیاری) که در `host`/`sni` لینک VLESS درج می‌شود؛ خالی = سرور اصلی
* **SNI**: دامنه‌ای که در پارامتر `sni` لینک VLESS می‌آید (اختیاری)؛ خالی = host یا SNI پیش‌فرض سراسری. این دامنه توسط دیمون Auto-Failover پایش می‌شود و در صورت مسدودی خودکار عوض می‌شود

## 🛡️ سامانه هوشمند سوئیچ خودکار SNI (Smart Auto-Failover Daemon — از Nyx Panel)

در زمان قطعی نت / فیلتر شدن SNI ها، لینک‌ها باید سریع به دامنه‌های سالم لیست سفید سوئیچ کنند. این دیمون دقیقاً همین کار را خودکار انجام می‌دهد:

* **پایش زنده پس‌زمینه**: هر ۶۰ ثانیه (قابل تنظیم) یک TLS handshake واقعی روی پورت 443 به سمت SNI کانفیگ‌های فعال زده می‌شود
* **تشخیص مسدودی (DPI Detection)**: اگر SNI پاسخ ندهد یا اتصال ریست شود، مسدود در نظر گرفته می‌شود
* **سوئیچ بدون تغییر لینک**: سالم‌ترین دامنه از لیست سفید (`ebanking.banksepah.ir`، `bmi.ir`، `arvancloud.ir`، `divar.ir`، `digikala.com`، `pypi.org`، `archive.ubuntu.com`، `yahoo.com`) جایگزین SNI مسدودشده می‌شود و فقط پارامتر `sni` داخل لینک‌ها عوض می‌شود — **لینک ساب کاربران بدون نیاز به تغییر متصل می‌ماند**
* **هشدار فوری تلگرام**: گزارش کامل سوئیچ (SNI قبلی → جدید + تاخیر) به پیوی ادمین ارسال می‌شود
* **اجرای دستی**: دکمه «پایش و سوئیچ (دستی)» در تنظیمات پنل و دکمه «🛡️ سوئیچ خودکار SNI» در ربات تلگرام

### تنظیمات

* **SNI پیش‌فرض سراسری**: در تنظیمات → «سامانه سوئیچ خودکار SNI» یا متغیر `AUTO_FAILOVER_SNI`؛ همه کانفیگ‌هایی که SNI اختصاصی ندارند از این مقدار استفاده می‌کنند
* **SNI اختصاصی هر کانفیگ**: هنگام ساخت/ویرایش کانفیگ، فیلد SNI را پر کنید
* **فعال/غیرفعال‌سازی**: از دکمه در تنظیمات یا متغیر `AUTO_FAILOVER_ENABLED` (پیش‌فرض `1`)
* **بازه پایش**: متغیر `AUTO_FAILOVER_INTERVAL` بر حسب ثانیه (پیش‌فرض `60`)

## 🌐 دامنه اختصاصی / CDN (از Nyx Panel)

اگر کانفیگ‌ها را پشت یک CDN (Cloudflare، آروان و...) قرار می‌دهید، لازم نیست آدرس اصلی Railway در لینک‌ها بیاید. دو راه دارید:

* **سراسری (همه کانفیگ‌ها)**: در داشبورد → تنظیمات → «دامنه اختصاصی / CDN» یک دامنه وارد کنید (یا متغیر محیطی `CDN_DOMAIN` را قبل از دیپلوی تنظیم کنید). از آن لحظه همه کانفیگ‌ها، لینک‌های ساب و صفحه‌های عمومی با آن دامنه ساخته می‌شوند (Host و SNI در لینک VLESS هم همین دامنه است). برای برگشت به حالت پیش‌فرض دکمه «حذف» را بزنید.
* **هر کانفیگ جداگانه**: هنگام ساخت یا ویرایش هر کانفیگ، فیلد «دامنه CDN اختصاصی» را پر کنید؛ این مقدار فقط روی همان کانفیگ اعمال می‌شود و بر تنظیمات سراسری مقدم است.

توجه: دامنه CDN باید به این سرویس اشاره کند و WebSocket/XHTTP آن فعال باشد (مثلاً در Cloudflare گزینه‌های WebSocket و gRPC را فعال کنید).

## 🗂 گروه‌های ساب (لینک ساب حرفه‌ای)

لینک ساب تکی (`/sub/{uuid}`) و لینک گروه، در لیست کلاینت چند ردیف جدا می‌سازند: **چهار پروتکل مشتری** (VLESS-WS، XHTTP، Trojan، VMess روی همان UUID)، بعد حجم و زمان، بعد لوکیشن. هدر استاندارد `subscription-userinfo` هم نوار حجم و تاریخ انقضا را در بالای ساب نشان می‌دهد.

به‌جای لینک ساب ساده، می‌تونید چند کانفیگ رو داخل یک **گروه ساب** قرار بدید تا یک **صفحه‌ی عمومی و زیبا** (`/p/{uuid_key}`) براشون ساخته بشه؛ شامل نمایش گرافیکی لیست کانفیگ‌ها، وضعیت هرکدوم، مصرف و QR Code، و در صورت نیاز قابل رمزدار کردن با پسورد. برای ساخت این لینک:

1. به بخش «گروه‌های ساب» در پنل (یا از طریق ربات تلگرام) بروید.
2. یک گروه جدید بسازید.
3. کانفیگ(های) مورد نظر را داخل همان گروه اضافه کنید.
4. لینک صفحه‌ی عمومی گروه را از همان‌جا کپی کنید.

## 🤖 ربات مدیریت تلگرام (اختیاری)

اگر می‌خواهید بدون باز کردن پنل وب، از طریق تلگرام کانفیگ‌ها را مدیریت کنید:

1. دو متغیر محیطی زیر را در تنظیمات سرویس Railway اضافه کنید:
   * `TELEGRAM_BOT_TOKEN` — توکن ربات از [@BotFather](https://t.me/BotFather)
   * `TELEGRAM_ADMIN_IDS` — آیدی عددی تلگرام ادمین‌های مجاز، جدا شده با کاما (مثلاً `123456789,987654321`)
2. بعد از ری‌استارت سرویس، به ربات پیام `/start` بدهید.

امکانات ربات:

* 📋 لیست، مشاهده، فعال/غیرفعال‌سازی و حذف کانفیگ‌ها
* ➕ ساخت کانفیگ جدید با یک ویزارد مرحله‌به‌مرحله (برچسب → پروتکل → Fingerprint → ALPN → پورت → محدودیت حجم → محدودیت سرعت → محدودیت آی‌پی → روز انقضا)
* 🔗 دریافت لینک اتصال VLESS و لینک ساب هر کانفیگ
* 🗂 ساخت و مدیریت گروه‌های ساب و دریافت لینک ساب حرفه‌ای مستقیماً داخل چت

## ⚙️ متغیرهای محیطی

| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `ADMIN_PASSWORD` | رمز عبور ورود به داشبورد وب | `X4GKING` |
| `SECRET_KEY` | کلید امضای سشن/پسورد؛ اگر تنظیم نشود، خودکار ساخته و روی دیسک ذخیره می‌شود | — |
| `DATA_DIR` | مسیر ذخیره‌سازی وضعیت (نیازمند Volume دائمی) | `/data` |
| `TELEGRAM_BOT_TOKEN` | توکن ربات تلگرام (اختیاری) | — |
| `TELEGRAM_ADMIN_IDS` | آیدی عددی ادمین‌های مجاز ربات، جدا با کاما (اختیاری) | — |
| `NODE_API_TOKEN` | توکن ثابت API نود (اختیاری؛ اگر خالی باشد از داخل پنل ساخته می‌شود) | ساخته‌شده خودکار |
| `RAILWAY_PUBLIC_DOMAIN` | دامنه عمومی سرویس؛ به‌صورت خودکار توسط Railway تنظیم می‌شود | `localhost` |
| `CDN_DOMAIN` | دامنه اختصاصی / CDN اولیه (مثلاً `cdn.mydomain.com`) که روی همه کانفیگ‌ها اعمال می‌شود؛ بعداً از داخل پنل هم قابل تغییر است | — |
| `AUTO_FAILOVER_ENABLED` | فعال‌سازی دیمون سوئیچ خودکار SNI | `1` |
| `AUTO_FAILOVER_INTERVAL` | بازه پایش SNI ها بر حسب ثانیه | `60` |
| `AUTO_FAILOVER_SNI` | SNI پیش‌فرض سراسری که همه کانفیگ‌ها استفاده می‌کنند و دیمون آن را پایش/سوئیچ می‌کند (خالی = هاست سرور) | — |
| `MULTIPATH_ENABLED` | فعال‌سازی موتور مسیریابی چندگانه کوانتومی | `1` |
| `MULTIPATH_INTERVAL` | بازه پایش ۴ مسیر بر حسب ثانیه | `15` |
| `PANIC_ALERTS_ENABLED` | ارسال هشدار حالت اضطراری به تلگرام ادمین | `1` |
| `LOAD_BALANCER_ENABLED` | فعال‌سازی لودبالانسر هوشمند سابسکریپشن | `1` |
| `LOAD_BALANCER_INTERVAL` | بازه نمره‌دهی سلامت کانفیگ‌ها بر حسب ثانیه | `30` |
| `BACKUP_ENABLED` | فعال‌سازی بکاپ خودکار دیتابیس در تلگرام | `1` |
| `BACKUP_INTERVAL_HOURS` | بازه بکاپ خودکار بر حسب ساعت | `24` |
| `WARP_ENABLED` | فعال‌سازی خروجی کلودفلر WARP | `0` |
| `WARP_PROXY` | آدرس پروکسی محلی WARP (wireproxy / warp-svc) | `socks5://127.0.0.1:40000` |
| `RELAY_BUF` | اندازه بافر رله (بایت) برای throughput بیشتر | `524288` |
| `READ_LIMIT` | سقف بافر خواندن جریان (جلوگیری از backpressure) | `2097152` |
| `BRAND_NAME` | نام برند پیش‌فرض در صفحه مشتری | `XR VPN` |
| `BRAND_LOGO_URL` | آدرس لوگوی صفحه مشتری (http/https) | — |
| `BRAND_ACCENT` | رنگ اصلی صفحه مشتری (HEX) | `#3B7CF6` |
| `BRAND_SUPPORT_TG` | آیدی تلگرام پشتیبانی در صفحه مشتری | — |

## 🖥️ مستر و نود همزمان

این پنل **هر دو نقش** را دارد:

* **مستر**: از منوی **نودها** پنل‌های XR، Marzban و 3x-ui را اضافه کنید، وضعیت و کانفیگ‌ها را ببینید و ساب تجمیعی بگیرید (`/api/nodes-subscription`).
* **نود**: از منوی **API نود** توکن و آدرس `/api/node/v1` را به پنل مستر دیگر بدهید، یا آدرس مستر را وارد کنید تا این نود خودش را آنجا ثبت کند.

### اتصال این XR به پنل مستر دیگر

### ۱) از داخل داشبورد

1. وارد `/dashboard` شوید و بخش **API مستر** را باز کنید.
2. آدرس API (`/api/node/v1`) و توکن را کپی کنید.
3. همین مقادیر را در پنل مستر وارد کنید.
4. اگر مستر هم XR است، آدرس و رمز/توکن مستر را همین‌جا بدهید تا این نود خودش را آنجا ثبت کند.

### ۲) از طریق API

همه مسیرها زیر `/api/node/v1` هستند و به هدر `Authorization: Bearer TOKEN` نیاز دارند:

| متد | مسیر | کار |
|---|---|---|
| GET | `/info` یا `/overview` | هویت، نسخه، آمار کلی |
| GET | `/health` | سلامت نود |
| GET | `/stats` | آمار + ترافیک ساعتی |
| GET | `/connections` | اتصالات زنده |
| GET / POST | `/configs` | لیست / ساخت کانفیگ |
| GET / PATCH / DELETE | `/configs/{uuid}` | مشاهده / ویرایش / حذف |
| GET | `/subscription` | ساب همه کانفیگ‌های فعال |
| GET | `/subs` | گروه‌های ساب |

توکن را می‌توانید با متغیر `NODE_API_TOKEN` پین کنید یا از داخل پنل بسازید و بچرخانید. اطلاعات ورود مستر در پاسخ API برنمی‌گردد.

## ⚛️ موتور مسیریابی چندگانه کوانتومی (Quantum MultiPath Engine — از Nyx v2.3.0)

هر ۱۵ ثانیه چهار مسیر ارتباطی مستقل به‌صورت **موازی** تست می‌شوند:

| مسیر | چه چیزی را می‌سنجد | چرا مهم است |
|---|---|---|
| 🛡️ `DIRECT_TLS` | دست‌دادن واقعی TLS با SNI کانفیگ | مسیر استاندارد و سریع‌ترین حالت |
| ☁️ `CDN_IRAN` | ابر آروان (PoP داخل ایران) | وقتی DPI مسیر مستقیم را می‌بندد |
| 🌐 `DNS_TUNNEL` | کوئری خام DNS روی پورت ۵۳ | پورت ۵۳ تقریباً هیچ‌وقت بسته نمی‌شود |
| 📡 `ICMP_PING` | عبور بستهٔ خام لایه ۳ | آخرین راه در قطعی کامل |

هر مسیر امتیاز ۰ تا ۱۰۰ می‌گیرد و وضعیت کلی شبکه به یکی از این پنج حالت طبقه‌بندی می‌شود:
`EXCELLENT` / `GOOD` / `DEGRADED` / `CRITICAL` / `PANIC`.

**حالت اضطراری (Panic Mode)** با منطق `Hysteresis` کار می‌کند: برای جلوگیری از آلارم کاذب،
فقط پس از **۳ چک متوالی ناموفق** فعال می‌شود و پس از **۲ چک متوالی موفق** پیام رفع بحران
همراه با مدت دقیق قطعی (دقیقه و ثانیه) به تلگرام ادمین ارسال می‌گردد.

**لودبالانسر هوشمند** هر ۳۰ ثانیه همه کانفیگ‌ها را نمره‌دهی می‌کند تا سالم‌ترین سرور
به‌صورت خودکار در ردیف اول `/sub-all` و `/sub-group/{key}` قرار بگیرد.

## 🔐 پروتکل‌های Trojan و VMess و ⚡ پکت فرگمنت

علاوه بر VLESS، پروتکل **Trojan روی WebSocket** با رلهٔ کامل و واقعی (استاندارد `trojan-gfw`)
پشتیبانی می‌شود. رمز عبور هر کانفیگ همان UUID آن است و احراز هویت با هش SHA-224 و
مقایسهٔ زمان‌ثابت انجام می‌گیرد.

پروتکل **VMess روی WebSocket** هم با رلهٔ واقعی و احراز هویت **AEAD** (AES-128-GCM /
ChaCha20-Poly1305) پشتیبانی می‌شود — همان پروتکلی که v2rayNG، Hiddify، NekoBox و
Streisand به‌صورت پیش‌فرض از آن استفاده می‌کنند. لینک آن به شکل استاندارد
`vmess://base64(JSON)` ساخته می‌شود و مسیر WebSocket آن `/vmess/{uuid}` است.

**پکت فرگمنت** با شکستن بستهٔ ClientHello، اجازه نمی‌دهد DPI مقدار SNI را بخواند:

| پریست | طول بسته | فاصله زمانی | مناسب |
|---|---|---|---|
| 📱 همراه اول (MCI) | `100-200` | `10-20` | بهترین پایداری روی نت همراه اول |
| 📡 ایرانسل | `50-150` | `5-15` | عبور مؤثر از فیلترینگ ایرانسل |
| ⚡ اینترانت | `10-60` | `2-10` | شبکه ملی و ترافیک داخلی |
| 🛠️ دستی | دلخواه | دلخواه | مقادیر اختصاصی خودتان |

## 🎨 برندینگ صفحه مشتری (`/subinfo/{uuid}`)

هر کانفیگ یک صفحهٔ اختصاصی و بدون نیاز به ورود دارد که می‌توانید کاملاً شخصی‌سازی کنید:
نام فروشگاه، لوگو، رنگ اصلی، دکمه‌های مستقیم **پشتیبانی** و **تمدید اشتراک**،
کادر اعلان به مشتریان، متن فوتر و باکس دانلود ۱-کلیک نرم‌افزارها
(v2rayNG، Streisand، v2rayN و Hiddify).

صفحه به‌صورت زنده حجم مصرفی، انقضا، لوکیشن و تعداد اتصال را نشان می‌دهد و
دکمه‌های کپی کانفیگ، کپی لینک ساب و کد QR دارد.

> 🔒 برای امنیت، فقط آدرس‌های `http/https` پذیرفته می‌شوند و همهٔ مقادیر ورودی escape می‌شوند.

## 💾 بکاپ خودکار در تلگرام و بازیابی ۱-کلیک

هر ۲۴ ساعت (قابل تنظیم) فایل کامل دیتابیس با کد اعتبارسنجی **SHA-256** به تلگرام ادمین
ارسال می‌شود. برای بازیابی کافی است **همان فایل را دوباره برای ربات بفرستید** — در چند ثانیه
همه کانفیگ‌ها، گروه‌ها، نودها و تنظیمات بازمی‌گردند.

* ✅ فایل دستکاری‌شده به‌خاطر نخواندن کد SHA-256 **رد می‌شود**
* ✅ قبل از هر بازیابی، یک **نسخهٔ ایمنی** از وضعیت فعلی ذخیره می‌شود
* ✅ امکان دانلود مستقیم فایل بکاپ از خود پنل

## 🌐 خروجی کلودفلر WARP

ترافیک مقصدهای انتخابی از شبکهٔ کلودفلر عبور می‌کند تا تحریم **OpenAI، ChatGPT، Claude،
Netflix و Spotify** رفع شود و IP واقعی سرور از دید مقصد پنهان بماند.

چون XR رلهٔ پایتونی خودش را دارد (نه Xray)، WARP از طریق یک پروکسی `SOCKS5/HTTP` محلی
(معمولاً [wireproxy](https://github.com/pufferffish/wireproxy)) روی همان سرور کار می‌کند:

```bash
WARP_ENABLED=1
WARP_PROXY=socks5://127.0.0.1:40000
```

دو حالت مسیریابی دارد: `domains` (فقط دامنه‌های لیست) و `all` (همه ترافیک).

> 🛡️ **fail-open**: اگر پروکسی WARP از کار بیفتد، اتصال به‌صورت خودکار مستقیم برقرار می‌شود
> تا سرویس کاربران هرگز قطع نشود.
